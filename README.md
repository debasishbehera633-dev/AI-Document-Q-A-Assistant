# AI Document Q&A Assistant

A local AI-powered document question-answering application built using RAG (Retrieval-Augmented Generation).

## Features

- Upload one or multiple PDF documents
- Extract and chunk PDF text
- Generate embeddings using Sentence Transformers
- Store and retrieve vectors using FAISS
- Generate answers locally using Ollama
- Display source/page references
- Chat history
- Relevance-based document retrieval
- No paid API required

## Tech Stack

- Python
- Streamlit
- Groq 
- Sentence Transformers
- FAISS
- PyPDF
- NumPy
